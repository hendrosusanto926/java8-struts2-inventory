# Screenshot Guide

Use these screens for the submission attachment:

1. Home page showing navigation and summary cards.
2. Item list with remaining stock visible.
3. Item create/edit form.
4. Inventory list showing T/W badges.
5. Inventory create/edit form.
6. Order list showing order totals.
7. Order create/edit form.
8. Report screen showing totals and per-item revenue.

## Suggested Demo Flow
1. Open the home page.
2. Navigate to Item Screen.
3. Open Item form.
4. Navigate to Inventory Screen.
5. Open Inventory form and create a Top Up or Withdrawal.
6. Navigate to Order Screen.
7. Open Order form and create an order.
8. Open Report Screen and capture the totals.
